# Chat Lab AI 1.7.1 Release Announcement

Chat Lab AI 1.7.1 aligns the declared Obsidian compatibility floor with secure
Codex credential storage and updates the chat composer to use Obsidian's CSS
helpers.

## Compatibility

- Requires Obsidian 1.11.4 or newer.
- Supports desktop and mobile.

## Fixes

- The manifest now reflects the Obsidian version required by the Codex
  `SecretStorage` API.
- The chat composer uses Obsidian CSS helpers for auto-sizing and reference
  overlay positioning.
