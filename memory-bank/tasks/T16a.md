## Description
Prevent sequential multi-agent conversations from amplifying full responses into
oversized provider requests. Preserve the full transcript for display and audit,
while passing later agents bounded selective summaries and structured tool facts.

## Acceptance Criteria
- [ ] Deterministically bound each agent contribution before reuse.
- [ ] Maintain a capped rolling summary with provenance and open questions.
- [ ] Share bounded structured tool facts so agents do not repeat searches unnecessarily.
- [ ] Enforce a provider output limit and test oversized-response behavior.
- [ ] Preserve full responses and tool results in the user-visible transcript.

## Implementation Details
Reuse the existing semantic-compaction contract and token-budgeting utilities,
but keep this ephemeral group context separate from long-term SessionSummarizer
memory. The deterministic projection is the safety boundary; an LLM summarizer
may be added later.
