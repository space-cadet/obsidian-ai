# T43a: Fix Rebuild Sync Index Title Resolution

*Created: 2026-08-21*
*Status: 🔄 ACTIVE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*

## Problem

`rebuildSyncIndex()` in `src/main.ts` still shows "Untitled Session" for all remote sessions because it lacks the title resolution fix that was applied to `triggerSync()`.

## Root Cause

`triggerSync()` (line ~804) builds a `titleMap` from local sessions and falls back to truncated session IDs:
```typescript
const titleMap = new Map(chatData.sessions?.map((s: any) => [s.id, s.title]) ?? []);
const title = titleMap.get(event.id) || this._getSessionTitle(event.id)?.trim() || `Session ${event.id.slice(0, 8)}…`;
```

`rebuildSyncIndex()` (line ~699) still uses the old code:
```typescript
const title = this._getSessionTitle(event.id)?.trim() || "Untitled session";
```

## Fix

Apply the same `titleMap` pattern to `rebuildSyncIndex()` before setting the progress handler.

## Acceptance Criteria

- [ ] Rebuild index shows session titles from local cache when available
- [ ] Falls back to `_getSessionTitle()` for sessions in sync cache
- [ ] Falls back to truncated ID (`Session abc123…`) for unknown remote sessions
- [ ] No "Untitled Session" appears in rebuild output
