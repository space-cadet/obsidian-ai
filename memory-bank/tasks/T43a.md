# T43a: Fix Rebuild Sync Index Title Resolution

*Created: 2026-08-21*
*Status: ✅ COMPLETE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*

## Problem

`rebuildSyncIndex()` in `src/main.ts` still shows "Untitled Session" for all remote sessions because it lacks the title resolution fix that was applied to `triggerSync()`.

## Root Cause

`triggerSync()` (line ~804) builds a `titleMap` from local sessions and falls back to truncated session IDs:
```typescript
const titleMap = new Map(chatData.sessions?.map((s: any) => [s.id, s.title]) ?? []);
const title = titleMap.get(event.id) || this._getSessionTitle(event.id)?.trim() || `Session ${event.id.slice(0, 8)}…`;
```

`rebuildSyncIndex()` (line ~699) still used the old code:
```typescript
const title = this._getSessionTitle(event.id)?.trim() || "Untitled session";
```

## Fix Applied (2026-08-21)

Applied the same `titleMap` pattern from `triggerSync()` to `rebuildSyncIndex()`:

```typescript
// Build title map from local sessions for better title resolution (T43a)
const chatData = await this.loadChatData();
const titleMap = new Map(chatData.sessions?.map((s: any) => [s.id, s.title]) ?? []);
```

Then in the progress handler:
```typescript
const title = titleMap.get(event.id) || this._getSessionTitle(event.id)?.trim() || `Session ${event.id.slice(0, 8)}…`;
```

This eliminates "Untitled Session" by trying:
1. Local session title from titleMap
2. Session title from sync cache (_getSessionTitle)
3. Truncated ID as last resort

## Acceptance Criteria

- [x] Rebuild index shows session titles from local cache when available
- [x] Falls back to `_getSessionTitle()` for sessions in sync cache
- [x] Falls back to truncated ID (`Session abc123…`) for unknown remote sessions
- [x] No "Untitled Session" appears in rebuild output
