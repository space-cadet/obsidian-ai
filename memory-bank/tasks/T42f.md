# T42f: Progress UI Improvements

*Created: 2026-08-19*
*Parent: T42*
*Status: 🔄 PENDING*
*Priority: P2*

## Objective

Enhance obsidian-ai's sync progress UI to match SyncIt's sidebar-style persistent progress display, in addition to the existing modal.

## Background

Obsidian-ai currently shows sync progress in a modal (`SyncProgressModal`) that blocks interaction. SyncIt shows progress in a sidebar view that's always visible and doesn't block. A sidebar or inline progress indicator would be more user-friendly.

## Implementation

### Option 1: Inline Status Badge
- Show sync status in the chat view header
- Icons: 🔄 syncing | ✅ synced | ⚠️ error
- Click to open detailed log

### Option 2: Persistent Sidebar Panel
- Similar to SyncIt's sidebar view
- Shows last sync time, session counts, conflicts
- Live progress during sync

### Option 3: Toast + Log
- Keep modal for active syncs
- Add toast notification on completion
- Add "View Sync Log" button in settings

## Acceptance Criteria
- [ ] Sync status visible without opening modal
- [ ] Last sync time shown somewhere in UI
- [ ] Error state clearly indicated
- [ ] Sync log accessible from settings
