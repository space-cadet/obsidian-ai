# Task: T48c — Rolling Conversation Summary and Compaction
*Created: 2026-08-23 02:02:32 IST*
*Status: 🔄 ACTIVE*

## Objective
Summarize older conversation turns when the token budget is exceeded, while
preserving recent turns, decisions, user intent, open questions, and useful tool
outcomes.

## Current Status — 2026-08-23

Research and design are complete; semantic rolling compaction has not yet been
implemented. T48c is the next implementation slice after the merged T48a/T48b
checkpoint. The full transcript remains authoritative; compaction must create
a separate model-history projection.

## Acceptance Criteria
- [ ] Token threshold is primary; turn threshold is fallback
- [ ] Recent turns are retained verbatim
- [ ] Older turns become a structured summary
- [ ] Compaction preserves tool context needed for follow-up actions
- [ ] Full transcript remains visible and exportable
- [ ] Compaction is observable and does not block normal chat unnecessarily
- [ ] The newest 3–5 messages are preserved verbatim (default: 4)
- [ ] Summaries retain decisions, constraints, user intent, open work, and tool outcomes
- [ ] Summaries are marked as derived context, not authoritative user text
- [ ] Exact older messages/tool results remain retrievable when precision matters
- [ ] The agent asks for clarification rather than inventing omitted historical detail
