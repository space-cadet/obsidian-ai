## Description

Complete the on-demand health-check and safe-repair experience for Chat Lab
plugin files, session indexes and transcripts, and memory stores. The read-only
health scanner is present in source (`66c90c4`); bounded findings UI and repair
previews were prototyped, then reverted. Restore them carefully and verify the
repair actions against real report findings without risking user data.

## Acceptance Criteria

- [ ] The health check remains read-only, bounded in scan size, and exports
  findings without transcript content.
- [ ] Long findings lists appear in a bounded, scrollable Settings container.
- [ ] Repairs require an explicit preview and show the affected records and
  files before applying changes.
- [ ] Every repair backs up files before writing and reports success or failure.
- [ ] Duplicate message IDs are resolved only when the records can be safely
  identified; conflicting content is preserved for review.
- [ ] Unindexed transcripts receive an explicit, safe disposition. Do not
  silently index, overwrite, or delete ambiguous files.
- [ ] Tests cover duplicate IDs, message-count mismatches, unindexed
  transcripts, backup creation, and failed repair writes.
- [ ] Mobile plugin-load and Settings acceptance are recorded separately from
  build and automated-test results.
