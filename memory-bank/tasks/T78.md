## Description

Prototype tags for saved chat sessions. Users can apply and remove tags in Chat
History and filter sessions by tag. An optional setting can suggest tags for
new sessions with a provider profile and model selected from configured AI
profiles.

## Acceptance Criteria

- [x] Store tags and automatic-tag pending state with session metadata, keeping
  older session data readable.
- [x] Add and remove tags from Chat History and filter saved sessions by tag.
- [x] Add an opt-in setting that selects a configured provider profile and its
  current model for automatic suggestions.
- [x] Generate suggestions for new sessions created while enabled, after the
  first exchange, using a bounded transcript excerpt.
- [x] Build the production plugin bundle and pass `git diff --check`.
- [ ] Verify the Settings and tag-edit/filter interactions in live Obsidian.

## Implementation Details

- `ChatSession.tags` stores normalized labels; the JSONL session index persists
  these without loading message files. `autoTagPending` is set only on new
  sessions created while the setting is enabled.
- The Settings control is opt-in and lists configured provider profiles with
  their selected models. Tag generation uses the existing `ChatApiManager`.
- A bounded excerpt of up to eight user/assistant messages, with each message
  capped at 600 characters, is sent to the selected provider. The setting
  explains this data flow. Failures are logged and do not interrupt chat.
- An in-flight set scoped to the shared session owner prevents duplicate
  suggestion requests across open chat panes.
- Chat History supports manual tag entry/removal and a tag filter. These
  changes are a branch prototype pending live UI acceptance.
- Tag edits update the session timestamp so the existing sync comparison can
  detect metadata changes.
