## Description

Add a `search_web` tool to the agentic tool suite, allowing the AI to search the web for current information. The user can choose between five search providers in Settings: DuckDuckGo (free, no API key), Brave Search API (requires key, 2000 free queries/month), Tavily (AI search, free tier), Exa (neural search, free tier), or SearXNG (self-hosted).

## Notes

- DuckDuckGo scraping may break if they change HTML layout. Brave API is more reliable.
- Tavily and Exa are AI-native search providers with free tiers. Good for LLM-optimized results.
- SearXNG requires a running instance. Good for privacy-conscious users.
- The `provider` field was removed from `ToolResult` return to avoid type error (`provider` not in `ToolResult` interface).
