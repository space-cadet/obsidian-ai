# T42e: Dry Run Mode

*Created: 2026-08-19*
*Parent: T42*
*Status: 🔄 Implemented in the sync panel; settings-panel acceptance still open*
*Priority: P2*

## Objective

Add a dry run mode that computes the sync plan and shows what would happen without actually uploading or downloading anything.

## Background

SyncIt has a full `performDryRun()` that scans, builds a plan, and simulates progress without transferring. Obsidian-ai has no equivalent — users must trigger sync and hope for the best. A dry run lets users preview changes before committing.

## Implementation

### Dry Run Flow
```typescript
async dryRun(): Promise<SyncPlan> {
    // 1. Compute plan normally
    const plan = await this.computeSyncPlan();
    
    // 2. Return plan without executing
    return plan;
}
```

### UI Integration
- Add "Dry Run" button next to "Sync Now" in settings
- Show results in a modal: "↑2 new, ↓1 updated, ⊘48 unchanged"
- Highlight conflicts if any

## Acceptance Criteria
- [x] Dry run calculates a plan without transferring sessions
- [x] The sync panel displays upload/download/skip counts
- [x] Cancel is checked during the simulated work

## Current Limit

Dry run is available in the integrated sync panel rather than as a separate settings-panel action. Its behavior for auxiliary plugin-data files should be verified and documented before it is treated as a complete preview of all sync work.
