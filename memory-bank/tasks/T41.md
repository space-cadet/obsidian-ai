## Description

Build a complete custom auto-updater for the obsidian-ai plugin that can check for updates from GitHub releases, download and install them, and rollback on failure. Support both stable and dev (pre-release) channels with automatic or manual update modes.

## Acceptance Criteria
- [x] Check GitHub releases for updates via API
- [x] Support stable vs dev (pre-release) channels
- [x] Auto-install stable updates silently (optional toggle)
- [x] Manual check with "Check Now" button in settings
- [x] Backup current plugin before install, rollback on failure
- [x] Cross-platform: works on desktop AND mobile
- [x] Semver comparison for version detection
- [x] Non-semver dev tags handled (e.g., `latest-dev`)
- [ ] Dev build release points to current HEAD (not old commit)
- [ ] Commit-hash comparison to prevent downgrade offers

## Implementation Details

### Architecture
- `src/updater/PluginUpdater.ts` — Core updater class
  - Fetches releases from GitHub API
  - Compares versions using semver
  - Downloads release asset
  - Backs up current installation
  - Extracts and installs new version
  - Rolls back on failure
- `src/settings-sections/updaterSettings.ts` — Settings UI
  - Channel selector (stable/dev)
  - Auto-install toggle
  - Manual "Check Now" button
  - Version display with channel suffix

### Key Design Decisions
- **Cross-platform:** Uses `requestUrl` + `app.vault.adapter` instead of Node.js `fs`/`https`
- **Mobile-safe:** No Node.js imports; pure Obsidian APIs
- **Backup strategy:** Copies current `main.js` + `manifest.json` + `styles.css` before install
- **Rollback:** Restores backup files if new version fails to load
