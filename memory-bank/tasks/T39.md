## Description

obsidian-git exposes git tools to obsidian-ai through a versioned provider
API. The provider lives in obsidian-git and owns all git execution and
credentials. obsidian-ai discovers the provider, registers its tools, and
runs them through its normal tool path. Whether a tool call prompts first is
controlled by obsidian-ai's existing auto-execute toggle — nothing else.
(T38's proposed approval-policy framework was rejected by Deepak on
2026-09-18: "Who told you to put in extra checks?! There already is an
auto execute toggle.")
