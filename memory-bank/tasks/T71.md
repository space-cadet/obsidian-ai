## Description

Fix chat-view scrolling regressions and performance on large sessions:
memoized rendering, follow-scroll during streaming, and the send-path race
that released follow mode. Ships on branch `perf/chat-scroll-settings-lag`
(alongside T24 index-only startup work).

## Acceptance Criteria

- [x] Message list renders without per-keystroke re-layout lag (memoized rows, `content-visibility`).
- [x] Streaming replies follow the bottom; user scroll-up interrupts follow.
- [x] Sending a message no longer jumps to a stale saved scroll position.
- [x] Mention pills render for every context item (root cause: only first match per text node replaced).
- [x] Large-session fixture exists for preview/tests; preview build repaired.
- [x] Regression tests cover follow-scroll behavior.
