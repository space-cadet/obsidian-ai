## Description

Define a separate, versioned contract through which SyncIt may later carry selected Chat Lab data without treating it as ordinary vault files.

## Acceptance Criteria

- [ ] The contract is separate from `integrationProvider`.
- [ ] It covers discovery, versioning, safe data scopes, and lifecycle.
- [ ] It identifies local-only fields such as credentials.
- [ ] It defines who owns transport, conflicts, deletion, and recovery.
- [ ] It defines behavior when either plugin is disabled or unavailable.
- [ ] It prevents both plugins from writing the same remote paths.
- [ ] SyncIt's `.obsidian/` exclusion remains the default whole-vault boundary.

## Implementation Details

The likely shape is an optional `dataSyncProvider` entry in the peer-plugin API. The existing tool-provider API should remain focused on AI capabilities and approval policy.
