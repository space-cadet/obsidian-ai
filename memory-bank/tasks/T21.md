## Description

Create a standalone CLI test harness that can exercise the obsidian-ai plugin's AI features without requiring Obsidian runtime. This enables testing of:
- Attachment resolution (markdown, image, PDF) → multimodal content parts
- Provider API calls (Gemini, OpenAI, Anthropic, etc.) with real API keys
- Streaming responses and tool calling
- Token estimation accuracy

## Test Scripts

### `scripts/test-attachments.ts`
```typescript
// Usage: npx tsx scripts/test-attachments.ts ~/vault/note.md ~/vault/image.png
import { createAttachment, resolveAttachments } from "../src/context/AttachmentEngine";

async function main(paths: string[]) {
  const attachments = paths.map(createAttachment);
  const parts = await resolveAttachments(attachments, mockApp, "gemini");
  console.log(JSON.stringify(parts, null, 2));
}
```

### `scripts/test-stream-chat.ts`
```typescript
// Usage: npx tsx scripts/test-stream-chat.ts "What is quantum gravity?"
import { ChatApiManager } from "../src/api";

async function main(prompt: string) {
  const api = new ChatApiManager(loadSettings(), mockApp);
  for await (const chunk of api.streamChat([
    { role: "user", content: prompt }
  ])) {
    process.stdout.write(chunk);
  }
}
```

### `scripts/test-multimodal.ts`


## Mock Vault

Since Obsidian `App` is not available in Node.js, create a minimal mock:
```typescript
const mockApp = {
  vault: {
    getAbstractFileByPath: (path: string) => ({ path, extension: path.split('.').pop() }),
    read: async (file: any) => fs.readFileSync(file.path, 'utf-8'),
    readBinary: async (file: any) => fs.readFileSync(file.path),
  }
} as any;
```

## API Key Management

- Load from `.env` file (`.env` in `.gitignore`)
- Or from `~/.obsidian-ai-test-keys.json` (user's home, never in repo)
- Or from environment variables: `GEMINI_API_KEY`, `OPENAI_API_KEY`, etc.
