## Description

Provide Codex account authentication as a provider separate from the existing
OpenAI API-key provider. Mobile users must be able to sign in and use Codex
without a connected desktop or Codex process. Desktop authentication must not
require the Codex desktop application. Implementation specifics and current
compatibility limits are maintained in
`memory-bank/implementation-details/external-service-authentication.md#codex`.
