## Description

Standalone benchmark harness for measuring and optimizing token usage in chat
sessions without requiring the full Obsidian runtime. The harness runs
outside the plugin, using the same context-building code paths, to enable
rapid iteration on compaction strategies, budget policies, and tool-result
handling.

This is a **cross-cutting infrastructure task** that serves multiple
workstreams: T48 (compaction), T48a (budget builder), T48d (usage display),
T6a (token accuracy), and T60d (search defaults). It is deliberately a
standalone top-level task rather than a T48 subtask to keep boundaries clean
and allow independent completion.
