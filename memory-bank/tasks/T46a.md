## Problem Statement

`src/hooks/useMessageActions.ts` is approximately 1,533 lines and combines
React state handling with request assembly, context construction, semantic
compaction, history budgeting, protocol selection, streaming, persistence,
tool execution, and approval handling. The hook is past the reconsideration
threshold recorded by T22 and is now a request-lifecycle module in practice.

## Objective

Move the non-UI lifecycle of one chat turn into a testable coordinator while
leaving the React hook as a thin state and command adapter.

## Scope

- Build the model request from the resolved context and model history.
- Select and run the native or OpenResponses protocol path.
- Coordinate streaming events, tool calls, approvals, continuation, and stop.
- Persist the final message and report lifecycle state back to the UI.
- Reuse the T60 capability resolution and T48/T62 history policy rather than
  creating new parallel rules.

## Acceptance Criteria

- [x] `useMessageActions.ts` no longer owns the complete request lifecycle.
- [x] The extracted coordinator can be tested without mounting React.
- [x] Native and OpenResponses paths share callback and persistence policy.
- [x] Tool approval and continuation preserve the existing result contract.
- [x] Context construction and model-history policy remain delegated to their
      owning modules.
- [x] Existing hook tests, agent-loop tests, TypeScript, and production build
      pass after each extraction slice.
- [x] The original hook remains a small composition layer with compatible
      behavior and imports.

## Implementation Progress — 2026-08-27

`src/agent/ChatTurnCoordinator.ts` provides a React-free `runChatTurn()` entry
point. It selects the native or OpenResponses loop, passes the same approval
and result callbacks to either path, and gives both paths the resolved tool
registry used for execution.

The main-branch `TurnLifecycle` remains the outer owner of request assembly,
context/history policy, persistence, interruption handling, and approval
lifecycle. Its tool-enabled send path uses the coordinator and
`ChatTurnOutput`; the duplicate feature-branch request and persistence helpers
were not retained because those responsibilities are already implemented by
`TurnLifecycle`.

The reconciled source is on `feat/t46-reconciled`, based on `origin/main` with
the feature branch's ToolExecutor decomposition integrated. Current sizes are
217 lines for `useMessageActions.ts`, 292 for `ToolExecutor.ts`, 363 for
`api.ts`, and 226 for `main.ts`. The full suite passes 43 test files / 362
tests, TypeScript passes, and the production build passes.
