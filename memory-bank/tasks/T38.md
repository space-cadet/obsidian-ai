any tool that writes. No framework is wanted.

(obsidian-ai main back to `f7db24a`). The design doc
`implementation-details/tool-approval-batch-audit-plan.md` was deleted.

## Decision

- Approval mechanism = the existing auto-execute toggle. Nothing else.
- No policy ladder, no batch plans, no audit log.
- If finer-grained tool approval is ever wanted, Deepak will specify it
  directly. Do not resurrect this task from the memory bank.
