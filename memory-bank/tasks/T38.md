## Description

Introduce a coherent tool-execution policy in place of the present binary
auto-apply switch. Extend safe bulk work beyond note creation through a shared
preview → approve → apply plan, and retain a bounded privacy-aware record of
every tool operation for later diagnosis.

## Acceptance Criteria

- [ ] Settings provide graduated approval modes from per-call confirmation to
  explicitly confirmed YOLO mode.
- [ ] YOLO skips approval prompts only; schema validation, path protections,
  batch limits, collision checks, and logging remain mandatory.
- [ ] Future mutation batches show an intelligible plan and per-file impact
  before one approval applies it.
- [ ] Batch application revalidates targets and reports applied, skipped, and
  failed items without hiding partial results.
- [ ] A separate JSONL operation audit log records plan, approval, and outcome
  events with configurable rotation and total-size limits.
- [ ] Logs omit raw note content, prompts, API keys, and tokens by default.

## Implementation Details

- Add a Tool Safety & Approval settings section with these policy levels:
  ask every call; auto-approve read-only tools; auto-approve safe creation;
  auto-approve reversible edits; and YOLO. Display a persistent active-policy
  indicator in the chat UI. Enabling YOLO needs a deliberate confirmation.
- Define typed batch plans rather than a generic array of arbitrary calls.
  Start with moves and structured patch/frontmatter edits. A plan must include
  target paths, operation-specific previews, collision findings, and expected
  content fingerprints for existing files. Apply rechecks those fingerprints.
- Defer bulk deletion until the common plan contract is proven, then require a
  prominent destructive summary and separate confirmation.
- Add a dedicated `ToolOperationLogger`, separate from `FileLogger`. Store
  concise JSONL events in the plugin directory: timestamp, session/model,
  tool and plan IDs, policy, target paths, duration, result counts, and
  redacted error/diff summaries. Rotate at a configurable per-file size,
  retain a configurable file count, and enforce a total-size cap.
- Add settings actions to export and clear the audit log. Any optional content
  preview must be opt-in and redacted.
