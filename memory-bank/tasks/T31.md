# T31: Chat Input Draft Auto-Save

*Created: 2026-07-29*
**Status**: 🔄 **IN_PROGRESS**
**Priority**: medium

## Problem

If the user has started typing a message but the app exits, crashes, or the plugin reloads before sending, the partially-typed text is lost. There is no recovery mechanism.

## Solution

Persist the current composer text as a `draft` field on the active `ChatSession`. The draft is saved debounced (500 ms) and restored when the session becomes active again.

## Scope

- Add `draft?: string` to `ChatSession` interface.
- In `ChatInput`: accept `draft` as an initial value; call `onDraftChange(text)` on every `handleInputChange` (debounced by the parent).
- In `ChatApp`: pass `activeSession?.draft` into `ChatInput`; debounce `setSessions` updates to write the draft; clear the draft on successful `onSend`.
- The existing `useChatSession` / `SessionStorage` pipeline will persist `draft` automatically because it is part of the session object.
- **Out of scope:** attachment auto-save (attachments remain ephemeral), per-tab draft isolation (handled naturally by session-scoped drafts).

## Files

| File | Change |
|------|--------|
| `src/types.ts` | Add `draft?: string` to `ChatSession` |
| `src/components/ChatInput.tsx` | Accept `draft` + `onDraftChange` props; restore draft on mount/edit |
| `src/components/ChatApp.tsx` | Wire debounced draft update; clear on send |
