## Description

The key differentiator from Obsidian Copilot. AI responses in the chat panel can be pushed directly into notes as inline diffs — using the exact same accept/discard UX already present in the inline tooltip — or used to create new notes. The `NoteEditingBridge` connects the chat panel to the CodeMirror diff machinery without modifying either.

## Context

The `diffExtension` (particularly `setGeneratedResponseEffect` and `setSelectionInfoEffect`) provides a complete diff + accept/discard pipeline that requires only two dispatched effects to activate. `NoteEditingBridge` is purely a bridge — it opens notes and dispatches effects; it does not reimplement any diff logic. This means the user experience is identical to the existing inline tooltip: familiar, consistent, no new UX to learn.
