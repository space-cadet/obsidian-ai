## Description

Define safe two-way behavior for plugin data when devices edit, replace, or delete the same item.

## Acceptance Criteria

- [x] Local-only changes upload.
- [x] Remote-only changes download.
- [x] Changes on both devices create a visible conflict.
- [x] The user can keep local, use remote, keep both, or cancel.
- [x] Local data is backed up before replacement.
- [x] Deletion records are kept so missing data is not mistaken for a deletion.
- [x] A deletion is propagated only when there is a known shared previous state.

## Implementation Details

Use a shared record for each file or component. It must remember the last state seen by both sides. If one side disappears without a known deletion record, stop and ask the user.
