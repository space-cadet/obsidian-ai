## Description

Allow users to export their plugin settings as JSON for backup and import them
later. Critical for migrating between devices or recovering from data loss.

## Implementation

### Files Created/Modified
- `src/settings-sections/exportImport.ts` — Export/import logic with API key redaction
- `src/settings-sections/SettingsTab.ts` — Wired nav button and render call
- `src/settings.ts` — Schema version field added

### Export
- Saves to vault root via `vault.adapter.write()` (works on desktop + mobile)
- Filename: `chat-lab-settings-YYYY-MM-DDTHH-MM-SS.json`
- API keys redacted by default (`***`)
- Optional "Export with secrets" for personal backups (warning button)

### Import
- Uses `FuzzySuggestModal` to pick from vault JSON files
- Schema version validation
- Profile merging by ID (existing profiles updated, new profiles added)
- User feedback: "X new profiles, Y updated"

### Security Fix (2026-08-19)

- Added `tavilyApiKey`, `exaApiKey`, `braveApiKey` to redaction list
