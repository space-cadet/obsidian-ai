## Description

Give settings, memory, persona, audit data, usage data, and sync metadata the same basic safety protections as chat-session payloads.

## Acceptance Criteria

- [ ] Encryption is applied consistently when enabled.
- [ ] Every transferred item has a checksum and version.
- [ ] Remote writes use a temporary file and safe replacement.
- [ ] Damaged or incomplete data is rejected.
- [ ] The result clearly says which item succeeded or failed.

## Implementation Details

Move the current `_syncTextFile()` behavior into a shared file-sync layer. Keep selection rules in `PluginDataManager`, but keep transfer safety in one place.
