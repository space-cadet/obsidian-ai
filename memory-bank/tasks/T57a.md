## Description

Give settings, memory, persona, audit data, usage data, and sync metadata the same basic safety protections as chat-session payloads.

## Acceptance Criteria

- [x] Encryption is applied consistently when enabled.
- [x] Every transferred item has a checksum and version.
- [x] Remote writes use a temporary file and safe replacement.
- [x] Damaged or incomplete data is rejected.
- [x] The result clearly says which item succeeded or failed.

## Implementation Details

Move the current `_syncTextFile()` behavior into a shared file-sync layer. Keep selection rules in `PluginDataManager`, but keep transfer safety in one place.
