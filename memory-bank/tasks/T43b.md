# T43b: Add Activity Indicators to Sync UI

*Created: 2026-08-21*
*Status: ✅ COMPLETE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*

## Problem

During sync (especially dry-run), the UI provided insufficient feedback. The RAF batching made dry-runs finish in a single frame, so users saw "Start" → "Complete" with no perceptible work happening. Controls were disabled but there was no visual activity indicator.

## Solution Applied (2026-08-21)

Added CSS animations and component changes for immediate visual feedback:

### CSS Added (styles.css)

```css
@keyframes sync-v2-spin { to { transform: rotate(360deg); } }
@keyframes sync-v2-pulse-bar { 0%, 100% { opacity: 1; } 50% { opacity: 0.5; } }
@keyframes sync-v2-shimmer { 0% { background-position: -200% 0; } 100% { background-position: 200% 0; } }

.sync-v2-spinner {
  display: inline-block;
  width: 16px; height: 16px;
  border: 2px solid var(--background-modifier-border);
  border-top-color: var(--interactive-accent);
  border-radius: 50%;
  animation: sync-v2-spin 0.8s linear infinite;
}

.sync-v2-progress-fill--active {
  animation: sync-v2-pulse-bar 1.5s ease-in-out infinite;
}

.sync-v2-item--pending {
  background: linear-gradient(90deg, ...);
  background-size: 200% 100%;
  animation: sync-v2-shimmer 2s ease-in-out infinite;
}
```

### Component Changes (ChatSyncPanel.tsx)

1. **Spinner in status heading** — Rotating border spinner appears next to "Syncing…" text
2. **Pulsing progress bar** — `sync-v2-progress-fill--active` class added during sync
3. **Pending item shimmer** — Items with `status === "pending"` get subtle shimmer animation

## Acceptance Criteria

- [x] Spinner/activity indicator visible within 100ms of clicking "Start sync"
- [x] Progress bar has pulsing animation while sync is active
- [x] File list items show "pending" state before completion
- [x] Animation stops immediately on cancel or completion
- [x] Works on tablet (low CPU overhead — pure CSS, no JS animation)
