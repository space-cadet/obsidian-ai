# T43b: Add Activity Indicators to Sync UI

*Created: 2026-08-21*
*Status: 🔄 ACTIVE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*

## Problem

During sync (especially dry-run), the UI provides insufficient feedback. The RAF batching makes dry-runs finish in a single frame, so users see "Start" → "Complete" with no perceptible work happening. Controls are disabled but there's no visual activity indicator.

## Current State

- Status text changes: "Ready" → "Syncing…" → "Complete"
- Progress bar appears but jumps 0% → 100% in one frame
- Button swaps to "Cancel"
- **No spinner, no pulsing animation, no hourglass**

## Requirements

1. **Immediate feedback on button click** (< 100ms) — disable controls, show spinner before sync starts
2. **Activity indicator during sync** — animated spinner/icon in status area, pulsing progress bar
3. **Per-item animation** — file list items appear with brief "pending" state before turning "done"

## Design Notes

Use CSS animations (not JS) for performance:
- `@keyframes spin` for spinner icon
- `@keyframes pulse` for progress bar during active sync
- `transition` for state changes (pending → done)

Keep it lightweight — no external libraries. Pure CSS + React state.

## Acceptance Criteria

- [ ] Spinner/activity indicator visible within 100ms of clicking "Start sync"
- [ ] Progress bar has pulsing animation while sync is active
- [ ] File list items show "pending" state before completion
- [ ] Animation stops immediately on cancel or completion
- [ ] Works on tablet (low CPU overhead)
