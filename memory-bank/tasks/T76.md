# T76: Latest Effective System Prompt Preview

## Status

**COMPLETE** — implementation and production build pass. Priority: HIGH

- **Started:** 2026-10-21
- **Completed:** 2026-10-21

## Objective

Let users inspect the complete generated system prompt that was most recently
sent to a model, in the existing Agent prompt modal, while keeping the shared
base prompt editable and resettable under T75.

## Dependencies

- T75: Editable Agent Prompt and Legacy Editor Removal

## Acceptance Criteria

- [x] The modal offers a view of the latest effective system prompt alongside
  the editable base prompt.
- [x] Single-agent chat captures the system message from final model history,
  including runtime tool-catalog guidance.
- [x] Group chat captures each participant's composed system message and labels
  it with the agent and model.
- [x] The preview is read-only and can be copied.
- [x] Switching prompt views preserves any unsaved base-prompt draft.
- [x] The snapshot is in-memory only and clears when Chat Lab reloads.
- [x] The UI explains that note and attachment bodies are sent as separate
  message context, outside the system prompt.
