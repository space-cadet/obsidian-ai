## Description

Build the vault context injection system. Users type `@` in the chat input to mention vault notes by name; those notes are read from the vault and injected as structured XML context blocks into the LLM prompt. Also supports auto-including the active note and selected text.

## Context Assembly Format

```
<context>
  <note name="Project Notes">...full content...</note>
  <active-note name="Current Draft">...content...</active-note>
  <selection>...highlighted text...</selection>
</context>

{{userMessage}}
```

## Context

The `@` mention system is similar to Copilot's `contextNotes` but simpler — no vector search, just direct file reads. The embed expander uses a depth limit of 2 to avoid infinite loops in circular note graphs. Token estimation uses a rough chars/4 approximation; exact tokenisation per model is deferred.
