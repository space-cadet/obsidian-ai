**Priority:** CRITICAL

## Problem

Three user-reported defects affected agentic vault work and multi-tab chats:

1. Gemini tool continuations failed with a missing `thought_signature` validation error.
2. The agent claimed it could batch-create notes while only a one-note `create_note` tool existed.
3. The shared model picker did not reliably restore a tab's profile when switching tabs.

## Implemented Contract

- The SDK adapter retains provider metadata on every tool call. `AgentLoop` returns the metadata on the exact reconstructed assistant tool-call part, preserving Gemini thought signatures for the next function-response step.
- `create_notes` creates 2–100 new Markdown notes in one approval. It rejects forbidden paths, duplicate batch paths, and existing notes before any write. It never overwrites a note.
- A chat session's `selectedProfileIds` and single-profile `profileId` are the source of truth. Selecting a tab restores its stored profile selection; changing the profile picker persists it on that tab; new tabs inherit the active tab's selection.
