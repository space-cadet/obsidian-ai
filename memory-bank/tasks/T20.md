## Description
Add focused chat-history workflows without redesigning the overall chat UI: select multiple messages with a long press and copy them, and provide compact per-session copy/export controls in the Chat History modal.

## Acceptance Criteria
- [x] Long press enters message selection mode; tapping toggles selection.
- [x] Selection toolbar provides selected count, Markdown copy, and cancel.
- [x] Selection resets when the active session changes.
- [x] Session picker is titled Chat History.
- [x] Per-session Copy and Export dropdowns provide Markdown, JSON, and JSONL actions.
- [x] Redundant format buttons are removed and action layout remains readable.
- [x] Tests, TypeScript, production build, and diff checks pass.

## Implementation Details
Selection state is owned by `useChatUI` and passed through `ChatMessages` to `MessageBubble`. `MessageBubble` uses a cancellable long-press timer and preserves ordinary click behavior. Selected messages are serialized with the existing `exportChat` utilities and copied as Markdown. `SessionPickerModal` keeps load, rename, delete, copy, and export actions independent; copy and export formats are grouped into compact dropdown menus.
