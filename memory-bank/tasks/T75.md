# T75: Editable Agent Prompt and Legacy Editor Removal

## Status

**COMPLETE** — implementation and production build pass. Priority: HIGH

- **Started:** 2026-10-21
- **Completed:** 2026-10-21

## Objective

Let users inspect, edit, and restore the shared main agent prompt, and remove
the legacy selection/cursor editor tooltip feature while preserving note edits
initiated from Chat Lab.

## Dependencies

- T43: Multi-User and Agent Chat with LaTeX Support
- T61: Self-Settings Agent Tools
- T5: In-Place Note Editing from Chat

## Acceptance Criteria

- [x] The built-in shared prompt directs agents to Obsidian's dollar-sign
  delimiters for inline and display math.
- [x] Single-agent and group-agent requests use the same editable base prompt.
- [x] Settings → Chat Defaults opens an existing-pattern modal with the full
  base prompt, Save, Cancel, and Reset to default.
- [x] Agent tools can read, update, and reset the prompt; mutations are gated
  by Developer mode, persisted, and audited without logging prompt contents.
- [x] Remove the selection/cursor tooltip, its prompt-history path, custom
  editor prompt commands, obsolete settings, and current documentation claims.
- [x] Keep Chat Apply-to-Note diff review available with accept/discard
  commands.
- [x] Preserve dated historical records of the former feature.

## Implementation Record — 2026-10-21

- Added `DEFAULT_AGENT_PROMPT` with the Obsidian `$...$` inline and `$$...$$`
  display math rule.
- Added `AgentPromptModal` under the existing Chat Defaults section. Reset
  loads the built-in prompt into the editor; Save applies it and Cancel leaves
  persisted settings unchanged.
- Added `get_agent_prompt`, `update_agent_prompt`, and `reset_agent_prompt`.
  Mutations require Developer mode and audit the action and prompt length.
- Removed `WidgetExtension`, editor selection/cursor prompts, custom editor
  command completion, prompt-history settings, and obsolete documentation.
  Kept the shared diff extension for chat-originated note changes.
- Updated current product and architecture notes. Earlier task/session
  records remain as dated history with a follow-up that clarifies the removal.
- The modal was extended under subtask T75a with a read-only, copyable view of
  the latest effective system prompt and agent-tool access to that snapshot.
