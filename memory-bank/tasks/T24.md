## Description
Implement persistent chat session storage using JSONL (JSON Lines) format for human-readable, append-only, git-friendly logs. Replace or supplement in-memory state with disk-backed sessions that survive Obsidian restarts.

## Implementation

### Phase 1: SessionStorage Core (0mu-a)
- **File:** `src/storage/session-storage.ts`
- **Class:** `SessionStorage`
- **Methods:**
  - `loadSession(id: string): ChatMessage[]` — reads `sessions/{id}.jsonl`, parses each line as JSON
  - `appendMessage(id: string, message: ChatMessage): void` — appends one JSONL line
  - `createSession(): { id: string, file: TFile }` — creates new `sessions/{uuid}.jsonl`, returns handle
- **Storage location:** `.obsidian/plugins/obsidian-ai/sessions/{uuid}.jsonl`

### Phase 2: ChatStorage Wrapper (0mu-b)
- **File:** `src/storage/ChatStorage.ts`
- **Class:** `ChatStorage` — async wrapper around SessionStorage
- **Methods:**
  - `saveSession(id, messages): Promise<void>`
  - `loadSession(id): Promise<ChatMessage[]>`
  - `listSessions(): Promise<SessionMetadata[]>`
  - `deleteSession(id): Promise<void>`
- **Integration:** Used by ChatApp for loading/saving conversation history

### Phase 3: Plugin Integration (0mu-c)
- **File:** `src/main.ts`
- **Changes:**
  - Added `sessionStorage: SessionStorage` property to `ObsidianAIPlugin`
  - Initialized in `onload()` with `app`, `manifest`, `logger` dependencies
  - Wired `ChatApp` to use `ChatStorage` for session persistence
- **Fix:** Added missing `contextPickerPathDisplay` to `ObsidianAISettings` interface (was breaking build)
- **Build:** `npm run build` passes ✅

### Migration Support
- **File:** `src/storage/Migration.ts`
- Handles migration from old in-memory format to JSONL
- **File:** `src/modals/MigrationPromptModal.ts`
- UI modal prompting user to migrate existing sessions
