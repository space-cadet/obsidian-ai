## Description

Defines and validates a composite scoring function that penalizes both token
waste AND information loss. Raw "savings percent" is insufficient — it rewards
aggressive truncation that destroys conversation coherence.

The goal is a single score that lets us rank configurations by "optimal" rather
than just "cheapest."

## Proposed Score

```
score = 0.5 × savings_percent
      + 0.3 × recent_preservation
      + 0.2 × content_retention
```

Where:
- `savings_percent` = (tokens_before - tokens_after) / tokens_before × 100
- `recent_preservation` = % of last N messages (N = preserveRecentMessages)
  that are kept intact (not truncated or dropped)
- `content_retention` = % of original tool result text preserved in history replay

Weights are provisional and may be tuned based on user preference data.

## Alternative Formulations

1. **Harmonic mean:** `score = 3 / (1/savings + 1/recent + 1/retention)`
   - Penalizes extreme tradeoffs more aggressively
2. **User-configurable weights:** Expose sliders in settings for
   "token savings priority" vs "conversation fidelity priority"
3. **Model-aware scoring:** Different weights for agent mode vs chat mode

## Acceptance Criteria

- [ ] Composite scoring function implemented in harness
- [ ] Produces stable rankings (same config wins across multiple fixtures)
- [ ] Scores correlate with perceived conversation quality
- [ ] Weights are documented and adjustable
- [ ] Compared against raw savings-percent rankings to show improvement
