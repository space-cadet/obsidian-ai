# T27: Fix Gemini Tool Calling — Missing thought_signature Error

**Status:** ✅ COMPLETED  
**Completed:** 2026-07-28
**Priority:** HIGH  
**Created:** 2026-07-28  

## Problem

When using Gemini as the model, tool calls fail with:

```
AI_APICallError: Function call is missing a thought_signature in functionCall parts.
This is required for tools to work correctly, and missing thought_signature
may lead to degraded model performance.
```

The error occurs during function calling when the agent tries to use tools like `read_note`. This is a Google Gemini-specific requirement — their function calling API requires "thought signatures" in function call parts.

## Root Cause

Gemini's API (via the Vercel AI SDK Google provider) expects a `thoughtSignature` field in function call responses. The current implementation likely doesn't include this field when constructing tool call payloads.

## Reference

- [Gemini API Thought Signatures Documentation](https://ai.google.dev/gemini-api/docs/thought-signatures)
- Error context: `default_api: read_note, position 20`

## Proposed Fix

1. **Investigate** how the Vercel AI SDK Google provider handles tool calls
2. **Add** `thoughtSignature` support in the tool calling pipeline
3. **Test** with Gemini model to verify tool calls work correctly
