## Overview

Add a `read_pdf` agent tool that extracts text content from PDF documents. The tool works with both online PDFs (via URL) and vault PDF files (via path). Two extraction backends are supported:

1. **Server-side** (default): PyMuPDF extraction service running on the user's VPS
2. **Client-side** (fallback): pdfjs-dist within Obsidian's Electron environment

Users configure the method via plugin settings with an "auto" mode that tries server first and falls back to client.

## Implementation

### Server-side PDF Extraction Service

- **Location**: `/home/cloudy/.openclaw/workspace/services/pdf-extract/`
- **Stack**: Python 3.12 + Flask + PyMuPDF (fitz) + gunicorn
- **Endpoint**: `https://quantumofgravity.com/relay/pdf-extract/`
- **Proxied through**: Apache `ProxyPass /relay/pdf-extract/ http://127.0.0.1:8082/`
- **Service**: `pdf-extract.service` (systemd, enabled, auto-restart)

**API**:
```
POST /extract
Body: { "url": "...", "max_pages": 50 }
Response: { "success": true, "metadata": {...}, "pages": [...], "full_text": "...", "total_word_count": N }
```

**Test result**: arXiv PDF, 2 pages extracted, 1202 words in ~1s.
