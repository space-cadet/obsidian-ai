# Task: T63 — Context Item Caching
*Created: 2026-08-26 22:15:00 IST*
*Status: 🆕 PROPOSED*

## Objective
Eliminate redundant vault I/O and token counting by caching resolved context
items within a chat session. If the user hasn't changed context items between
turns, reuse the previously resolved content.

## Motivation
`handleSend` calls `resolveContextItems()` on **every single message**:
```typescript
const resolved = await resolveContextItems(
  sendContextItems,
  plugin.app,
  plugin.settings.maxContextTokens || 8000,
);
```

For a 5000-token note attached as context, this means:
- Reading the file from disk every turn
- Expanding embeds every turn
- Token-counting every turn
- Truncating every turn

The result is identical if the note hasn't changed. This is pure overhead.

## Acceptance Criteria
- [ ] Context items cached per-session keyed by `(filePath, mtime, tokenBudget)`
- [ ] Cache invalidated when:
  - Context items list changes (added/removed/reordered)
  - File modification time changes
  - Token budget setting changes
- [ ] Cache stored in `ChatSession` state (not persisted — session-scoped)
- [ ] First turn: cache miss, resolve normally
- [ ] Second+ turn with same context: cache hit, skip resolve
- [ ] Memory impact bounded: max ~8KB per cached item (truncated content)
- [ ] Observable in token counter: lower "request tokens" on cache hit turns

## Implementation Notes

### Cache Key Design
```typescript
interface ContextCacheKey {
  itemPaths: string[];      // Ordered list of context item paths
  mtimes: number[];         // Modification times (from vault)
  tokenBudget: number;      // maxContextTokens at resolution time
}

interface ContextCacheEntry {
  key: ContextCacheKey;
  resolved: ResolvedContextItem[];
  estimatedTokens: number;
}
```

### Integration Point
In `useMessageActions.ts` `handleSend`:

```typescript
// Before
const resolved = await resolveContextItems(sendContextItems, plugin.app, maxTokens);

// After
const cacheKey = buildContextCacheKey(sendContextItems, plugin.app, maxTokens);
const cached = session.contextItemCache?.get(cacheKey);
const resolved = cached ?? await resolveContextItems(sendContextItems, plugin.app, maxTokens);
if (!cached) session.contextItemCache.set(cacheKey, resolved);
```

### Token Impact
| Scenario | Without Cache | With Cache | Savings |
|----------|---------------|------------|---------|
| 10-turn chat, 1 large note context | 10 × 5000 = 50k tokens resolved | 1 × 5000 = 5k tokens resolved | **90%** |
