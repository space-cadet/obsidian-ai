# Task: T61 — Self-Settings Agent Tools
*Created: 2026-08-26 22:15:00 IST*
*Status: 🆕 PROPOSED*

## Objective
Give the AI agent the ability to introspect and modify its own plugin
configuration through canonical agent tools. This enables self-diagnosis of
token usage, runtime optimization suggestions, and autonomous behavior tuning
without user manual intervention.

## Motivation
During token-usage investigation (T48, T60), the agent had no way to know its
own `maxContextMessages`, `maxToolResultTokens`, or `enableAgentTools`
settings. Users had to manually relay configuration. Self-settings tools close
this loop.

## Acceptance Criteria
- [ ] `read_settings` tool: returns sanitized plugin settings (no API keys,
  passwords, or tokens)
- [ ] `update_setting` tool: modifies whitelisted settings when Developer Mode
  is enabled
- [ ] Developer Mode toggle in Advanced Settings (default: false)
- [ ] Immutable settings rejected with clear error (apiKey, password,
  secretAccessKey, authToken, passphrase, provider profiles)
- [ ] Audit trail: all setting changes logged to console and/or memory audit
- [ ] Tools registered in canonical registry (T60) if available, else
  ToolExecutor directly
- [ ] Works with both native AI SDK loop and OpenResponses loop

## Proposed Settings Whitelist (Mutable)
| Key | Type | Description |
|-----|------|-------------|
| `maxContextTokens` | number | Token budget for context items |
| `maxContextMessages` | number | Max history messages sent to model |
| `maxRequestTokens` | number | Model request token limit |
| `preserveRecentMessages` | number | Messages kept in full during compaction |
| `compactionTriggerTokens` | number | Token threshold for semantic compaction |
| `maxToolResultTokens` | number | Max tokens per tool result in replay |
| `requestResponseReserveTokens` | number | Reserve for response + tool output |
| `enableAgentTools` | boolean | Enable agentic tool calling |
| `autoApply` | boolean | Auto-apply note edits |
| `maxAgentSteps` | number | Max tool rounds per request |
| `messageHistory` | boolean | Enable chat history persistence |
| `includeActiveNote` | boolean | Auto-include active note as context |
| `showFullRequestTokens` | boolean | Show full payload token count |
| `developerMode` | boolean | Enable self-settings modification |

```typescript
      }

  }
}

{
  name: "update_setting",
  description: "Update a plugin setting. Requires developerMode=true.",
  parameters: {
    properties: {

      value: { type: "any" }
    },
    required: ["key", "value"]
  }
}
```
