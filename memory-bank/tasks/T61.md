# T61: Self-Settings Agent Tools

## Status

**COMPLETE** — implementation and integration acceptance pass. Priority: HIGH

**Last Updated:** 2026-09-09 16:30 IST

## Description

Give the AI agent the ability to read and modify its own plugin settings via tools, gated behind a "Developer mode" toggle.

## Motivation

During token usage investigation, the AI couldn't see its own configuration (e.g., `maxContextMessages`, `maxToolResultTokens`). A `read_settings` tool would let it self-diagnose issues. A `update_setting` tool (developer mode only) would let power users adjust behavior mid-conversation.

## Proposed Tools

### `read_settings`
- Returns sanitized plugin settings
- **Redacts**: `apiKey`, `password`, `secret`, `auth` fields, provider profile credentials
- **Includes**: token budgets, toggles, file paths, feature flags

### `update_setting`
- Only available when `developerMode === true` (new setting)
- **Mutable whitelist**: safe behavior, request-budget, compaction, tool-replay, and debug/diagnostics settings; credentials, provider profiles, paths, and loop-safety controls remain immutable
- **Immutable**: All credentials, provider profiles, API keys, file paths
- Validates type/range before applying
- Saves settings automatically

## UI Changes

Add "Developer mode" toggle to the Agent Tools section. It is marked as an
advanced control and is shown when the overall advanced-settings visibility
toggle is enabled. When enabled:
- Registers `read_settings` and `update_setting` tools
- Shows a warning that AI can modify settings

## Security Considerations

- Never expose credentials via `read_settings`
- Audit log all `update_setting` calls
- Confirm destructive changes with user

## Dependencies

- None (builds on existing tool registry)

  save the settings, and write an audit record.
- The Agent Tools section includes the developer-mode toggle inside its nested
  Advanced settings disclosure.
- The remaining acceptance work is focused integration coverage for both tool

- No separate confirmation prompt is implemented; developer mode is the
  current user-controlled gate for setting changes.
