# T42d: Server Signature for Cache Invalidation

*Created: 2026-08-19*
*Parent: T42*
*Status: 🔄 PENDING*
*Priority: P1*

## Objective

Implement server signature hashing so that changing WebDAV credentials or URL automatically invalidates the local sync cache, preventing stale data from being used against a new server.

## Background

Obsidian-ai's `LocalCache` uses a namespace like `obsidian-ai-sync-default` but doesn't detect when the user switches servers. A stale cache after server migration means the plugin thinks sessions are synced when they're not. SyncIt solves this by hashing `url|username|baseDir` into a `serverSignature` stored in the index.

## Implementation

### Signature Generation
```typescript
function makeServerSignature(config: WebDAVConfig): string {
    const raw = `${config.url.trim()}|${config.username.trim()}|${config.prefix || ''}`;
    // Simple hash — SHA-256 or even a string hash
    return hashString(raw);
}
```

### Cache Invalidation
- Store `serverSignature` in `LocalCache` metadata
- On sync init: compare current signature to stored signature
- If mismatch: clear cache and rebuild from scratch
- If match: use cached data
