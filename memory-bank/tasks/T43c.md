# T43c: Extend Sync to All Plugin Data

*Created: 2026-08-21*
*Status: ✅ COMPLETE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*
*Related: T42 (Remote Chat Storage & Sync), T49 (Settings Export and Import)*

## Problem

Currently sync only handles `ChatSession[]`. Other plugin data is device-local:

| Data | Location | Current | Desired |
|------|----------|---------|---------|
| Chat sessions | `sessions/` (JSONL) or `data.json` | ✅ Syncs | ✅ Syncs |
| **Settings** | `data.json` | ❌ Local | ✅ Sync |
| **AI Memory** | `.obsidian-ai/memory.json` | ❌ Local | ✅ Sync |
| **Sync index** | Plugin data | ❌ Per-device | ✅ Shared |

## Solution Applied (2026-08-21)

Implemented Option C: bundle settings + sync index into a single encrypted JSON blob.

### Changes

1. **StorageAdapter interface** — Added `readText(path)` method
2. **WebDAVStorageAdapter** — Implemented `readText()` using existing `GET` infrastructure
3. **main.ts** — Added three methods:
   - `_serializePluginData()` — Creates JSON blob minus API keys/passwords
   - `_deserializePluginData()` — Merges remote data with local (preserving credentials)
   - `syncPluginData()` — Uploads/downloads the blob

### Data Synced
- Provider profiles (minus API keys)
- Prompts, preferences, settings
- Sync index (shared across devices)

### Data NOT Synced (security)
- API keys
- WebDAV/S3 passwords
- Local-only paths

### Conflict Resolution
- Last-write-wins with notification
- Remote timestamp compared to `lastSyncTime`
- Credential fields never overwritten from remote

### Integration
- `syncPluginData()` is called automatically at the end of `triggerSync()` when session sync succeeds
- Respects the same `syncDirection` setting (both/upload/download)

## Acceptance Criteria
