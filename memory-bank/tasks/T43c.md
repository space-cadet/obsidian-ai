# T43c: Extend Sync to All Plugin Data

*Created: 2026-08-21*
*Status: 🔄 ACTIVE*
*Parent: T43 (Integrate Sync UI into Chat Lab)*
*Related: T42 (Remote Chat Storage & Sync), T49 (Settings Export and Import)*

## Problem

Currently sync only handles `ChatSession[]`. Other plugin data is device-local:

| Data | Location | Current | Desired |
|------|----------|---------|---------|
| Chat sessions | `sessions/` (JSONL) or `data.json` | ✅ Syncs | ✅ Syncs |
| **Settings** | `data.json` | ❌ Local | ✅ Sync |
| **AI Memory** | `.obsidian-ai/memory.json` | ❌ Local | ✅ Sync |
| **Memory audit** | `.obsidian-ai/memory-audit.jsonl` | ❌ Local | ⚠️ Optional |
| **Sync index** | Plugin data | ❌ Per-device | ✅ Shared |
| **Sync logs** | `.obsidian-ai/sync-logs.jsonl` | ❌ Local | ⚠️ Optional |

## Architecture Gap

`StorageAdapter` is session-centric: `putSession`, `getSession`, `listSessions`. Extending for arbitrary files requires generic file operations.

## Options

### Option A: Extend StorageAdapter
Add `putFile(path, data)`, `getFile(path)`, `listFiles(path)` to interface. All backends implement.

### Option B: Separate sync channel
Use existing WebDAV/S3 connection for a second sync pass that handles non-session files.

### Option C: Plugin data as encrypted blob
Bundle settings + memory + index into a single encrypted JSON blob, sync as one file.

## Recommendation

**Option C for Phase 1** — simplest, atomic, versioned:
- Serialize settings (minus API keys), memory, sync index to JSON
- Encrypt with same passphrase as sessions
- Store as `plugin-data.json` on remote
- Download → decrypt → merge (conflict: last-write-wins or manual)

**Option A for Phase 2** — if granular sync needed later.

## Acceptance Criteria

- [ ] Settings sync (provider profiles, prompts, preferences)
- [ ] AI Memory sync (`memory.json`)
- [ ] Sync index shared across devices (prevents false conflicts)
- [ ] API keys excluded from sync (security)
- [ ] Conflict resolution: last-write-wins with notification
- [ ] Backward compatible: devices without this feature ignore `plugin-data.json`

## Files

- `src/sync/StorageAdapter.ts` — May need `writeText()`/`readText()` (already exists)
- `src/sync/SyncEngine.ts` — Add plugin data sync pass
- `src/main.ts` — Serialize/deserialize plugin data
- `src/settings.ts` — Exclude sensitive fields from sync
