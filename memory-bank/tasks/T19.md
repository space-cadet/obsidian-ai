# T19: File Attachments for Chat Messages

## Overview
Enable users to attach markdown files, images, and PDFs to chat messages so the LLM can consume their content (not just reference them). Images are sent as base64 via multimodal content parts. PDFs are sent as `FilePart` (Gemini) or extracted text (other providers). Markdown files are inlined as text.

## Goals
1. Attach vault files (markdown, images, PDFs) to chat messages
2. LLM sees/reads attachment content, not just references
3. UI shows attachment chips below user messages
4. Works across providers with capability-aware fallback

## Non-Goals
- File upload from outside the vault (drag from Finder) — deferred
- Audio/video attachments — deferred
- Real-time camera capture — deferred

## Provider Support Matrix

| Provider | Images | PDFs | Notes |
|----------|--------|------|-------|
| **Gemini** | ✅ Native base64 | ✅ Native `FilePart` | Best support |

## Implementation Plan

### Phase 1: Types & Data Model
**Files:** `src/types.ts`
- Add `Attachment` interface
- Make `ChatMessage.content` union: `string | Array<TextPart | ImagePart | FilePart>`
- Add `attachments?: Attachment[]` to `ChatMessage`

### Phase 2: Attachment Resolution Engine
**Files:** `src/context/AttachmentEngine.ts` (new)
- `resolveAttachment(att, app, maxImageSize)` → content parts
- Markdown: read file, return as text block
- Image: read as base64, resize to max 1024px, return `ImagePart`
- PDF: return `FilePart` for Gemini; extract text or skip for others

### Phase 3: ChatInput UI
**Files:** `src/components/ChatInput.tsx`
- Add 📎 dropdown menu: "Attach note…", "Attach image…", "Attach PDF…"
- Show attachment chips above textarea
- Drag-and-drop from vault (optional)
- Pass `attachments` to `onSend(text, attachments)`

### Phase 4: Message Display
**Files:** `src/components/MessageBubble.tsx`
- Render attachment chips (📄 note.md, 🖼️ image.png, 📑 doc.pdf)
- Click to open file in Obsidian

### Phase 5: API Refactor
**Files:** `src/api.ts`
- Update `streamChat()` / `streamChatWithTools()` to accept multimodal messages
- Convert `ImagePart` / `FilePart` to provider-specific formats

### Phase 6: ChatApp Integration
**Files:** `src/components/ChatApp.tsx`
- In `handleSend()`: resolve attachments before building chat messages
- Build user message as multimodal content array
- Group chat: broadcast attachments to all participants

### Phase 7: Testing
- Test with Gemini (images + PDFs)
- Test with OpenAI/Anthropic (images only)
- Test group chat with attachments
