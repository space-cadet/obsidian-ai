# T62: Tool Payload Elision in History Replay

## Status

**COMPLETED** — Implemented in `feat/t62-tool-payload-elision` (commits `58ab538` → `9d03d27`).

## Description

Reduce token usage in history replay by eliding (omitting) tool call payloads, similar to OpenClaw's default behavior.

## Problem

`buildHistoryWithTools` reconstructed the full Vercel AI SDK shape for every tool call, replaying complete tool arguments and results on every turn. With `maxToolResultTokens` defaulting to 4000, a 10-turn conversation with 2 tools per turn could burn ~40k tokens just in history replay.

## Solution

Added `toolHistoryMode: "elide" | "preserve"` setting (default `"elide"`):

- **"elide" mode**: Tool call `input` → `"[elided]"`, tool result → `"[N chars, elided]"`
- **"preserve" mode**: Full detail retained for debugging

## Elision Behavior

| Mode | Tool Call Input | Tool Result | Use Case |
|------|----------------|-------------|----------|
| **elide** (default) | `"[elided]"` | `"[N chars, elided]"` | Normal use — saves ~99% tokens |
| **preserve** | Full `args` JSON | Full/truncated content | Debugging |

## Impact

On 10-turn conversation with 2 tools per turn (2000-token results):
- **Before**: ~40,000 tokens in history replay
- **After (elide)**: ~400 tokens
- **Savings**: ~99%

Full results remain in saved transcript — only model-facing history is elided.

## Verification: Debug Commands

A built-in debug command system lets you verify elision in real time:

| Command | Output |
|---------|--------|
| `!debug history` | Dumps model-facing history (shows `[elided]` placeholders) |
| `!debug tokens` | Token counts, tool call tallies, model info |
| `!debug context` | Context items/attachments in last message |
| `!debug help` | Command reference |

> 🔒 Debug output is local-only — never sent to the AI model.

## Important Distinction: Two Separate Truncations

**`maxToolResultTokens`** (current turn, existing behavior):
- Controls how much of a tool result the AI sees **when the tool runs**
- Default: **4000 tokens**
- If a file is 8000 tokens, the AI only sees the first 4000 in the current turn
- This is why the AI says "the rest was elided" — it's seeing a truncated result

**`toolHistoryMode`** (history replay, T62):
- Controls how tool results appear in **later turns' history**
- Default: `"elide"` — shows `"[N chars, elided]"` instead of actual content
- Only affects replay; the AI already saw the truncated result in turn 1

To read longer files in a single turn, increase `maxToolResultTokens` in Settings → Chat Defaults.
