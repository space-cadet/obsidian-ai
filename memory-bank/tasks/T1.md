## Description

Build the persistent sidebar chat panel as an Obsidian `ItemView`. This is the foundational UI surface for the new chat interface. All other chat-related tasks (T2, T3, T5, T6) depend on this being in place.

## Completion Criteria

- ⬜ Add `react`, `react-dom`, `@types/react`, `@types/react-dom` to dependencies
- ⬜ Register `InlineAIChatView` (extends `ItemView`) with `CHAT_VIEWTYPE = "inlineai-chat-view"`
- ⬜ Add ribbon icon (`message-square`) that opens the chat panel
- ⬜ Add Obsidian command "Open InlineAI Chat" (configurable hotkey)
- ⬜ `activateChatView()`: open in right sidebar, prevent duplicates
- ⬜ Mount/unmount React root in `onOpen()` / `onClose()`
- ⬜ Implement `<ActionBar>`: New Chat, Load Chat dropdown, Settings link
- ⬜ Implement `<ChatMessages>`: scrollable thread, user/assistant bubbles
- ⬜ Implement `<MessageBubble>`: markdown rendering, copy button, timestamps
- ⬜ Implement streaming-aware display (`currentAiMessage` progressive render)
- ⬜ Implement `<ContextBar>`: context chip display, remove chip, add note button
- ⬜ Implement `<ChatInput>`: multiline textarea, Enter to send, Shift+Enter for newline
- ⬜ Implement Stop button with AbortController during streaming
- ⬜ Style with plain CSS (no Tailwind dependency unless agreed)
- ⬜ Existing inline tooltip unaffected (no regressions)
