## Description

Collect anonymized usage statistics to help prioritize features and identify
issues. Strictly opt-in — disabled by default with full disclosure.

### Design
- **Opt-in:** Disabled by default, first-run dialog asked once
- **Anonymous:** Random UUID stored in localStorage, not derived from user data
- **Silent fail:** Network errors don't nag users
- **Flush:** Queue flushed every 60s or on plugin unload
- **Endpoint:** `https://quantumofgravity.com/telemetry`

### Data Collected
- AI provider type (e.g., DeepSeek, OpenAI)
- Feature usage counts (e.g., group chat, tool calling)
- Conversation length in turns (bucketed ranges)
- Error types (e.g., rate_limit, not error messages)
- Plugin version

### Data NEVER Collected
- Message content, prompts, or responses
- API keys or credentials
- File names, paths, or vault structure
- Personal identity or IP address
- Obsidian installation ID

### Events
- `chat_started` — provider, single/group chat
- `tool_used` — tool name, success/failure
