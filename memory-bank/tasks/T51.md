## Original Description (for reference)

Collect anonymized usage statistics to help prioritize features and identify issues. Strictly opt-in — disabled by default with full disclosure.

### Data Collected (when enabled)
- AI provider type
- Feature usage counts
- Conversation length (bucketed)
- Error types
- Plugin version

### Data NEVER Collected
- Message content, prompts, responses
- API keys, credentials
- File names, paths, vault structure
- Identity, IP address
