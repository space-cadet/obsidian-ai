## Description

T62's default `"elide"` mode breaks multi-turn agent workflows by replacing all
previous tool results with `[N chars, elided]` placeholders. The agent reads
content in turn N but cannot see it in turn N+1, making multi-step analysis
impossible.

**Real impact:** Agent reading a 22,000-character grammar note gets
`[22749 chars, elided]` in the next turn's history — zero usable content
remains. The agent cannot extract patterns, build on prior reads, or perform
any work that references earlier tool results.

## Current Behavior

| Mode | Turn N (live) | Turn N+1 (history replay) |
|------|--------------|---------------------------|
| `"elide"` (default) | Full result (truncated to `maxToolResultTokens`) | `[22749 chars, elided]` |
| `"preserve"` | Full result (truncated) | Full result (truncated) |

**Workaround:** Switch `toolHistoryMode` to `"preserve"` in Settings → Chat
Defaults. This restores full functionality but loses T62's ~99% token savings.

## Root Cause

T62 elision was designed for user-facing chat replay where the human already
saw the tool output. It is too aggressive for agentic workflows where the agent
must retain tool result context across turns to build cumulative understanding.

## Candidate Solutions (Open-Ended)

### Option 1: Smart Elision
Replace `[N chars, elided]` with a structured summary:
```
[elided: 22749 chars]
Excerpt: "The grammar notes cover 22 index sections including..."
```
Preserves ~95% token savings while giving the agent enough context to know
*what* was read and *whether* to re-read.

### Option 2: Agent-Mode Auto-Preserve
When `enableAgentTools === true`, automatically skip elision for tool results.
Agent workflows get full history; regular chat keeps the token savings.

### Option 3: Per-Session Toggle
Agent or user can request `"preserve"` mode for the current session via:
- Chat command (`!mode preserve`)
- Tool call (`switch_elision_mode`)
- UI toggle in chat header

Reverts to default on new session.

### Option 4: Pin/Unpin Results
Agent explicitly marks specific tool results as "retain in history" after
reading them. Unpinned results elide normally. Gives the agent control without
requiring advance prediction.

### Option 5: Per-File Elision (User Suggested)
Agent specifies elision mode per file/tool call:
```typescript
read_note({ path: "Grammar Notes", elision: "preserve" })
```

**Concern:** Requires the agent to predict in advance which files it will need
across turns, before it knows their content. May be too granular.

### Option 6: Hybrid — Recent vs. Older
Only elide tool results older than N turns. Recent results (last 2-3 turns)
remain fully visible; older ones get elided. Balances token savings with
workflow continuity.

## Open Questions
