## Regression Context

The Settings panel that shipped with the initial T9 implementation included re-entrancy guards (`isDisplaying`/`pendingRefresh`) to prevent cascading `display()` calls. These protections were lost in a subsequent edit, causing the panel to become **corrupted** — `saveSettings(true)` could trigger nested `display()` calls while a previous `display()` was still running, producing **infinite re-entrant loops** and **memory leaks** from uncleaned DOM nodes and closure references.

GPT 5.4 Medium performed a clean rewrite of `src/settings.ts` that:
- Restored the `isDisplaying`/`pendingRefresh` guard mechanism
- Restructured the panel into a sectioned layout with a styled hero header
- Re-instated the model fetch/search picker behavior that had regressed
- Added matching CSS in `styles.css`
