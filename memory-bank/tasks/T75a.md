## Objective

Let users inspect the complete generated system prompt most recently sent to a
model in the existing Agent prompt modal, alongside the editable shared base
prompt, and let agent tools read that latest prompt.

## Acceptance Criteria

- [x] The modal offers a view of the latest effective system prompt alongside
  the editable base prompt.
- [x] Single-agent chat captures the final system message, including runtime
  tool-catalog guidance.
- [x] Group chat captures each participant's composed system message and labels
  it with the agent and model.
- [x] The preview is read-only, can be copied, and clears when Chat Lab reloads.
- [x] Switching prompt views preserves any unsaved base-prompt draft.
- [x] The UI explains that note and attachment bodies are separate message
  context, outside the system prompt.
- [x] `get_agent_prompt` returns the shared base prompt and the latest captured
  system prompt, including its content, label, and capture time.
