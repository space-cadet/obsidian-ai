# T30: Add System Information Tool for Agent

**Status:** ✅ COMPLETED  
**Completed:** 2026-07-28
**Priority:** MEDIUM  
**Created:** 2026-07-28  

## Problem

The agent cannot determine basic system information that is accessible to Obsidian, such as:
- Current date and time
- System timezone
- Obsidian app version
- Plugin version
- Platform (desktop/mobile, OS)
- Vault name and path

This limits the agent's ability to provide context-aware responses (e.g., "What notes did I create today?" requires knowing "today's" date).

## Proposed Solution

Add a `get_system_info` tool (or similar) that exposes system-level information to the agent. Alternatively, inject this information into the system prompt context.

## Information to Expose

| Information | Source | Use Case |
|-------------|--------|----------|
| Current date/time | `new Date().toISOString()` | Time-aware queries |
| Timezone | `Intl.DateTimeFormat().resolvedOptions().timeZone` | Scheduling, time context |
| Obsidian version | `app.version` | Debugging, compatibility |
| Plugin version | `manifest.json` version | Debugging |
| Platform | `Platform.isMobile`, `Platform.isDesktop` | Platform-specific advice |
| OS | `Platform.isWin`, `Platform.isMac`, `Platform.isLinux` | OS-specific paths/commands |
| Vault name | `app.vault.getName()` | Context identification |
| Vault path | `app.vault.adapter.basePath` (desktop only) | File operations |
| System locale | `navigator.language` | Language-aware responses |

## Implementation Options

### Option A: System Prompt Injection (Recommended)
Inject a system information block into every prompt:
```
[System Context]
Current date: 2026-07-28
Current time: 15:05:00 IST
Timezone: Asia/Kolkata
Platform: Android (mobile)
Obsidian version: 1.7.0
Plugin version: 1.2.4
Vault: MyVault
```

**Pros:** Always available, no tool call needed, zero latency  
**Cons:** Uses token budget, may not be needed for every query

### Option B: `get_system_info` Tool
Add a tool the agent can call when needed.

**Pros:** On-demand, saves tokens when not needed  
**Cons:** Requires agent to know to call it, extra round-trip

### Option C: Both
Inject basic info (date/time) into system prompt + provide tool for detailed info.
