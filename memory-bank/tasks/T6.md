## Description

Prevent context window overflows by tracking estimated token usage across conversation history and attached context. Provides truncation and a lightweight message-limit fallback. Adds a visual indicator in the chat UI showing how much context budget remains.

## Token Budget Allocation

```
Total budget: 8,000 tokens (configurable)

Allocation:
  System prompt:     ~500  (fixed)
  Context notes:    ~2,000  (truncated by ContextEngine, T3)
  Conversation:     ~4,500  (oldest turns dropped via maxContextMessages)
  Response reserve: ~1,000  (headroom for AI output)
```

## Context

This v1 implementation is deliberately lightweight. Instead of a full token-based conversation manager that calculates total tokens and drops turns dynamically, we use a simple `maxContextMessages` count limit. This is easy to understand, predictable, and prevents most context overflow issues. A more sophisticated token-budget-aware turn dropper can be added later if needed.
