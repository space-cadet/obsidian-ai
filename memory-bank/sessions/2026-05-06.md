## Session Notes
- AI SDK v6.0.174 installed. `streamText({ tools, stopWhen: stepCountIs(1) })` yields single-step streaming.
- `tool()` helper with Zod 3.x causes TS type inference explosion. Official fix is Zod 4.1.8+ or `moduleResolution: "nodenext"`. Current workaround is `any` casts.
- `@mention` adds note content to system prompt (no tool call needed); `[[wikilink]]` inserts text reference (motivates LLM to call `read_note`).
