## Context and Working State

This session addressed two issues:

**T10 Fix**: The model discovery feature was already implemented with provider-specific fetchers, but fetched model lists were not persisted. Every click of "Fetch models" made a fresh API call. The fix stores models in `ProviderProfile.modelCache` with a timestamp, checks the cache before fetching, and provides a refresh button in the picker modal. The cache is invalidated when any profile configuration changes.

**T6 Implementation**: Instead of the full token-budget-aware conversation manager from the original design, we implemented a lightweight version focused on practical value:
- Shared `tokenEstimator.ts` module for consistent token estimation across the codebase
- `maxContextMessages` setting provides a simple, understandable limit on conversation history
- Token usage indicator in ContextBar gives visual feedback on context budget consumption
