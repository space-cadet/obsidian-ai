## Context and Working State

**Code Status**: Built and passing. `main.js` rebuilt at 2026-05-09 11:51:05 IST after all source changes.

**Crash Theory**: Chromium/Electron bug triggered by rapid DOM mutations concurrent with smooth-scroll animation. The `SIGTRAP` on `ares_dns_rr_get_ttl` suggests a V8/libc-ares interaction during DOM cleanup. Working theory: smooth-scroll + unmount race condition.

**Key Decisions Made**:
- ErrorBoundary logs to disk immediately via `flushNow()` so crash data survives renderer restart.
- `scrollIntoView` behavior changed to `"auto"` as a precaution — removes animation from the unmount/mount transition path.
- `patch_note` uses simple string `split().join()` for `replace_all` rather than regex, keeping it literal and predictable.
- `edit_section` splits on `\n` and searches for heading lines starting with `# ` to find the target section.
