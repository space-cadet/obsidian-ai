## Context and Working State
Added a toggle button to the chat ActionBar that lets users switch between automatic and manual tool approval on the fly. When auto-approve is ON, the AI executes tools immediately. When OFF, each tool call pauses for manual approval via the existing pending-tool UI. The button shows visual state (accent color when active) and displays a Notice on toggle. Also added `saveSettings()` to the `ChatPluginLike` interface so the chat panel can persist the toggle state.
