## User Requests

1. **ETag comparison instead of timestamps** — Sessions were re-downloading every sync due to clock skew between server and local machine.
2. **Terminal-style progress modal** — Sparse progress display needed redesign. User wanted simple terminal log style with all relevant metrics.
3. **Sync log files** — Remote folder had `last-sync-time.txt`, should be a proper log file recording every sync session. Local plugin folder should also keep a record.
4. **Cancel button doesn't stop sync** — Cancel just closed modal, sync continued in background.

---

## Implementation

### ETag Comparison (`be3c3bb`)
- Changed `StorageAdapter.putSession()` to return `{ etag?: string; modifiedAt?: number }`
- `WebDAVStorageAdapter` extracts ETag from PUT response headers
- `LocalCache.markSynced()` stores `_etag` alongside `_remoteModifiedAt`
- `SyncEngine.computeSyncPlan()` compares ETags first, falls back to timestamp if ETags unavailable
- Result: No more false re-downloads

### Terminal-Style Progress Modal (`29ad150`)
- Rewrote `SyncProgressModal` from scratch:
  - Header with progress bar (count + percentage)
  - Scrollable terminal-style log container
  - Per-session lines with title (not ID hash), direction icon, status
  - Elapsed time counter
  - Background / Cancel / Done buttons
- Modal stays open after sync completes to show results

### Sync Log Files (`29ad150`)
- Created `SyncLogger` class with dual logging:
  - **Local**: `.obsidian/plugins/obsidian-ai/sync.log` — append-only, capped at ~500 lines
  - **Remote**: `obsidian-ai-sync/sync.log` — written via `StorageAdapter.writeText()`
- Added `writeText(path, content)` to `StorageAdapter` interface
- `WebDAVStorageAdapter.writeText()` creates parent directories via `mkcol()`
- Log format: `ISO timestamp [device] action sessionId "title" — message`

### Cancel Support (`deff496`)
- Added `_cancelled` flag to `SyncEngine`
- `cancel()` method sets flag; `resetCancellation()` clears it
- `sync()` checks `_cancelled` between sessions (not mid-upload)
- Current session finishes, then sync stops with "Cancelled by user" error
- Modal cancel button: shows "Cancelling...", disables itself, stays open for results
