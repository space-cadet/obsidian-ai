## Edit Chunk 2: T13a — Tool Call Context Persistence Bug Fix

### Files Modified
- `src/hooks/useMessageActions.ts` — Replaced history building with `buildHistoryWithTools()` (+159 lines, -9 lines)

### Bug Summary
Tool call results were stripped from conversation history. `buildReplayContent()` only included text content, ignoring `contentParts`/`toolCalls`. LLM forgot prior tool executions.

### Fix
`buildHistoryWithTools()` reconstructs Vercel AI SDK-compatible message shapes:
- Assistant messages with tool calls → `assistant` msg (text + tool-call parts) + `tool` msg (tool-result parts)
- Uses `contentParts` when available, falls back to `toolCalls` array
