## LLM-Powered Session Naming

**Commit**: `0c9ebd8`

### Files Modified
- `src/components/ChatApp.tsx`

### Features
- `generateSessionTitleLLM()`: async function calling the active LLM
  - System prompt: "Produce a concise title (3–6 words). Output ONLY the title."
  - Sends first 6 messages, capped at 200 chars each
  - Strips code blocks → `[code]`, JSON → `[data]`
  - Strips quotes from response if model adds them
  - Falls back to `null` on error or bad response

- **Manual rename** (wand button): shows "🪄 Asking model…", calls LLM first, falls back to heuristic
- **Auto-name**: uses LLM naming with `Set` ref (`llmNamedRef`) to avoid re-calling for same session
- **Token cost**: ~200–400 tokens per naming call (minimal)

### Fallback
- Both auto and manual fall back to existing heuristic `generateSessionTitle()` if LLM fails
