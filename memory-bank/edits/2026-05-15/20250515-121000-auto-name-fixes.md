#### 12:10:00 IST — Auto-naming fixes: replace g flag, threshold, UI controls
- **Code commit**: `4538159` — `fix(auto-name): fix session auto-naming and add UI controls`
- Files changed: `src/components/ChatApp.tsx` (+42 lines), `src/components/ActionBar.tsx` (+24 lines)
- Build: ✅ tsc + esbuild pass cleanly

## Fixes Applied

### 1. `generateSessionTitle()`: Added `g` flag to `replace()`
**Problem**: Only first `<context>` tag was stripped. Multiple context items leaked into title.
```typescript
// Before: "B.md</context> question"
const clean = text.replace(/<context>[\s\S]*?<\/context>/, "").trim();
// After: "question"
const clean = text.replace(/<context>[\s\S]*?<\/context>/g, "").trim();
```

### 2. Auto-title threshold lowered from `>= 2` to `>= 1`
**Problem**: Most sessions never reached 2 user messages, so single-exchange sessions stayed untitled.
**Fix**: `userMsgs.length >= 1` — names after first user message.

### 3. Removed date-fallback guard
**Problem**: `if (title !== "Chat ${date}")` blocked naming context-only messages.
**Fix**: Any generated title (even date fallback) is applied — better than empty.

### 4. New UI controls in ActionBar
- **Auto-name toggle** (✨ Auto / ✨ Off): Toggles `autoNameSessions` setting with Notice feedback
- **Manual rename** (✏️ Rename): Immediately generates title from first user message and applies it

**Props added to ActionBar**: `autoNameSessions`, `onToggleAutoName`, `onManualRename`
