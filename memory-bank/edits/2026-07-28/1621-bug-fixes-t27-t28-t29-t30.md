### T27: Fix Gemini Tool Calling — Missing thought_signature Error ✅

**Problem:** When using Gemini as the model, tool calls failed with:
```
AI_APICallError: Function call is missing a thought_signature in functionCall parts.
```

**Root Cause:** Gemini's API (via Vercel AI SDK Google provider) requires "thought signatures" in function call responses when using structured outputs.

**Fix:** Added Gemini-specific provider option in `src/api.ts`:
```typescript
const providerOptions = {
    ...getThinkingProviderOptions(activeProfile, thinkingEnabled),
    ...(activeProfile.provider === "gemini" ? {
        google: { structuredOutputs: false },
    } : {}),
};
```

**Files Modified:**
- `src/api.ts` — `streamChatWithTools()` method

**Implementation Doc:** `memory-bank/implementation-details/gemini-tool-calling-fix.md`

### T28: Fix Obsidian Note Link Click Crash ✅

**Problem:** When the agent returned messages containing Obsidian wiki-links (`[[Note Name]]`), clicking them crashed the entire Obsidian app.

**Root Cause:** `MarkdownRenderer.render()` converts wiki-links to HTML `<a>` tags. In the chat panel (a React component, not a native MarkdownView), Obsidian's link handler couldn't resolve the click context and crashed.

**Fix:** Added `setupLinkInterception()` function in `src/components/MessageBubble.tsx`:
- Intercepts all click events on `<a>` tags within rendered message content
- Routes internal links through `app.workspace.openLinkText()`
- Opens external URLs in browser
- Catches errors to prevent crashes

**Files Modified:**
- `src/components/MessageBubble.tsx` — Added `setupLinkInterception()`, applied in `TextSegment` and `LegacyContent`

**Implementation Doc:** `memory-bank/implementation-details/note-link-interception.md`

### T29: Android Background Processing ⏸️ DEFERRED

**Problem:** On Android, when Obsidian goes to background, obsidian-ai stops generating/streaming the AI reply.

**Investigation Results (2026-07-28):**
- Cloned and examined AI Tagger Universe source — it has NO special background handling
- Obsidian API provides no mobile lifecycle hooks (`onResume`, `onPause`, etc.)
- Android WebView pausing JavaScript execution is platform behavior, not a plugin bug
- AI Tagger Universe "works" because it doesn't stream (single request/response)

**Decision:** DEFERRED per user request. Accept mobile limitation. Desktop = full streaming, Mobile = pauses on background.

**Status:** Investigation complete. No code changes needed.
